Docker:
Install docker for linux:
sudo apt update
sudo apt install docker.io -y
sudo systemctl start docker
sudo systemctl enable docker
docker --version


Install docker desktop for windows
docker version ---> to check the docker version 
docker info ---->to get entire information about it
docker ps ----> to list the containers running
docker ps -a ---> to visualize all the running containers
docker images --->to list the created images
docker pull nginx
docker run -d -p 8081:80 nginx
Use the url http://localhost:8081 and access the browser.


Create own docker image:
I have created a docker folder inside that i created 
vi dockerfile
Code pasted inside dockerfile:FROM nginx
COPY index.html /usr/share/nginx/html/index.html
Create the html page with the name given in the dockerfile
Paste the content
Create the image using: docker build -t devops-nginx .    ---> . refers “Use the current directory as the build context”
Now run the image using: docker run -d -p 8082:80 devops-nginx
Open the browser and check: http://localhost:8082
