NETWORKING BASICS:
IP address → Identity of a machine
Example: 192.168.1.10
Port → Door number
Example:
80 → HTTP
443 → HTTPS
22 → SSH

DNS - Domain name system:
Human-friendly name → Machine IP

Docker & Networking:
Container has its own IP
Containers talk via bridge network
Port mapping:
docker run -p 8080:80 nginx
Meaning:
Host 8080 → Container 80
📌 Most Docker issues = wrong port mapping

CI/CD (Jenkins) & Networking:
Webhook → GitHub notifies Jenkins
Firewall rules → Allow traffic
Ports → Jenkins runs on 8080
📌 If pipeline fails:
Server unreachable
Port blocked
DNS not resolving

Kubernetes Networking:
Basics:
Pod → Has IP
Service → Stable IP / DNS
Ingress → External access
Pods die & recreate → IP changes
Service gives stable networking

Cloud Networking (AWS / Azure):
Cloud = networking + servers
Must-know terms:
VPC → Private network
Subnet → Smaller network
Internet Gateway → Internet access
Security Group → Virtual firewall
Example:
Allow 8080 → App works
Block 8080 → App fails
📌 70% cloud issues = security group / firewall

Terraform & Networking:
Terraform creates networking as code.
What you define:
VPC
Subnet
Routing
Firewall rules
Example:
port = 22
cidr = 0.0.0.0/0
📌 One wrong port = server unreachable

Monitoring & Networking:
Monitoring depends on network flow.
What is monitored?
Response time
Traffic
Errors
Example:
High latency → Network issue
Service down → Port blocked / DNS fail
📌 Monitoring tells you where networking breaks

Check Active Ports
🔹 Windows
netstat -ano
🔹 Linux
ss -tuln

DNS:
nslookup google.com

Test Web Connectivity:
curl https://www.google.com
If HTML appears → Internet + DNS + HTTPS all working ✅

NAT = Network Address Translation:
Router converts private IP → public IP
Without NAT ❌
Private IPs cannot access Internet
NAT is why:
Many devices share one public IP
Home Wi-Fi works

Firewall:
Firewall = Security guard
It decides:
Which IP can connect
Which Port is allowed

Transmission Control Protocol (TCP) : Reliable delivery
Communications standard that enables application programs and computing devices to exchange messages over a network.
Used by:
HTTP / HTTPS
SSH
Database connections

UDP (User Datagram Protocol): Fast delivery
It is a faster, connectionless protocol that sends data without guarantees
Used by:
Video calls
Live streaming
DNS queries
📌 Speed > reliability
