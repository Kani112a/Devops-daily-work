1.Git (Version Control):
Tool	    Difference

2.Docker (Containerization):
Tool	    Difference
Podman	    Docker-compatible, rootless
CRI-O	    Kubernetes-focused runtime
containerd	Lightweight runtime (used internally)
LXC/LXD	    System containers, not app-focused
Docker = easiest
Podman = secure enterprise choice

3.Jenkins (CI/CD)
Tool	        Difference

GitLab CI/CD	Integrated with GitLab
CircleCI	    Fast SaaS
Travis CI	    Simple, declining
Argo CD	        GitOps-based CD
Jenkins = powerful
GitHub Actions = modern & easy
